# Perubahan & Fitur Baru (2026-08-07)

## Fitur Baru: Group Activation System

### Command
- **`/botonline`** - Aktifkan bot di grup (owner-cuma, grup-cuma)
- **`/botoffline`** - Nonaktifkan bot di grup (owner-cuma, grup-cuma)

### Sistem
- Default: semua grup **inactive** sejak moment pertama bot di-setup
- Bot hanya merespons jika grup sudah di-aktifkan melalui `/botonline`
- Data persistence di sheet `GroupSettings` (GroupJID, GroupName, IsActive, timestamps)

### Updated: Command `/alert`
- **No duplicate notifications**: user yang di database & di grup hanya menerima 1x (satu) notifikasi
- Hanya mengirim ke **active groups only**
- Kirim private message ke user yang `terdaftar` tapi `BUKAN member grup mana pun`

## Bug Fixes

### 1. /alert Duplicate Notifications
**Masalah**: User yang terdaftar di database DAN member grup akan menerima 2 pesan (private + group mention)

**Solusi**: 
- Build `Set` of ALL group participant JIDs sebelum loop user
- Skip user kalau dia di dalam `Set` jadi gak kirim private
- Kirim group message hanya ke active groups

**File**: `index.js` → `/alert` case (sekitar line 1088)
- Baris S: Collect all group participants ke Set
- Baris T: Loop users, cek `!allGroupJids.has(user.jid)`
- Baris U: Kirim ke active groups only (filter `groupSetting.isActive`)

---

### 2. setGroupActive Function Bug
**Masalah**: Baris baru (user baru running `/botonline`) gagal save karena menggunakan `update` ke `GroupSettings!A1` (OVERWRITE header instead of APPEND)

**Solusi**: 
- Gunakan `append` dengan `insertDataOption: "INSERT_ROWS"` untuk baris baru
- Gunakan `update` untuk baris sudah ada

**File**: `sheets.js` → `setGroupActive()` (sekitar line 569-590)

---

### 3. PERSONAL_ONLY_COMMANDS Block Error
**Masalah**: Block ini blocked finance/todo commands (`/rekap`, `/massuk`, `/todo`) in groups **EVEN when active**. Jadi user kena `/botonline` tetep gak bisa pakai fitur.

**Solusi**: 
- Pisahkan command kedalam `TRULY_PERSONAL_ONLY` (command yang BENAR-BENAR cuma untuk private)
- Finance (`/massuk`, `/keluar`, `/rekap`, `/riwayat`, `/unduhrekap`)
- Todo (`/todo`, `/listtodo`, `/done`) - SEKARANG diperbolehkan

**File**: `index.js` → `handleCommand` (sekitar line 418-429)
- V: Buat `TRULY_PERSONAL_ONLY` array
- W: Check ini baru dipakai setelah activation check

---

### 4. Helper Document Fixed (For debugging)
**Masalah**: `getGroupSetting()` selalu return `null` untuk semua JID termasuk grup yang "aktif" dari hasil testing-node sebelumnya. New section in PROJECT_CONTEXT.md helps debugging.

**Solusi**: Add new section "7b. Group Activation System (dipilih fitur baru)" ke PROJECT_CONTEXT.md untuk dokumentasi cepat debug.
